# 통합 부동산 매물 찾기 부동산 플랫폼 (기업연계 프로젝트)


수행기간 

·2025.05~2025.06 


수행 인원

·백엔드: 7명, 프론트엔드: 4명, UI/UX: 2명


프로젝트 목적

· 기존 부동산 플랫폼은 세부 조건 설정이 어렵고 매물 정보가 분산되어 있어

효율적인 탐색이 어려워 부동산 관련 솔루션을 지속적으로 개발하고,

AI를 통한 고객 서비스 향상이 목표


달성 목표

· 사용자의 자연어를 이해하는 AI챗봇과 통합 매물 비교 기능을 제공하여

더 빠르고 직관적인 주거 탐색 경험을 제공하고자 함


사용 기술 및 개발 환경 (본인 역할 기준) 

· 언어: java(JDK17)

· 프레임워크: Spring Boot

· Database: PostgreSQL

· ORM: Spring Data JPA

· API: RESTful API 설계 및 구현

· 협업: GitHub, WBS, notion, slack
